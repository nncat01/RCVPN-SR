# RCVPN-SR

Automatic generation of RULE-SET `.list` files for the [Shadowrocket](https://apps.apple.com/us/app/shadowrocket/id932747118) proxy/VPN client

The source files used are Sing-box `.srs` files from the [hydraponique/roscomvpn-routing](https://github.com/hydraponique/roscomvpn-routing) repository

Built based on the parser from  [Master-Yoba/shadowrocket-rules](https://github.com/Master-Yoba/shadowrocket-rules)

In theory, it should also be compatible with [Surge](https://apps.apple.com/us/app/surge-5/id1442620678)
